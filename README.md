# 🔐 PassGen

一个简洁、美观且实用的随机密码生成器。

支持中英文切换、批量生成密码、自定义排除字符，完全本地运行，注重隐私保护。

## ✨ 特性

- 中英文界面一键切换
- 支持批量生成密码（最多30个）
- 可自定义密码长度（8-32位）
- 可选择字符类型（大写/小写/数字/符号）
- 默认排除易混淆字符，支持自定义添加
- 一键复制单个或所有密码
- 纯前端本地运行，无需网络

## 🚀 使用方法

1. 下载本项目
2. 双击 `index.html` 文件在浏览器中打开即可使用
3. 无需安装，无需联网

## 🛠 技术

- HTML5 + CSS3 + 原生 JavaScript
- 无任何第三方框架
- 完全本地运行
